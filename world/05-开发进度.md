## 2. 现在能跑什么

```bash
cd world/prototype
node server.js          # http://localhost:4173
npm test                # 115 个测试
node test-sim.js        # 5 个种子 × 2.5 个世界日
node test-cycles.js     # 资源循环
node sync-check.js journal.json   # 用另一台机器导出的日志校验并重建世界
```

- 零依赖，`npm install` 不需要。
- 每 10 秒自动存档；重启后按离线时间快进，并给出关键事件摘要。
- 不配置模型时，规则大脑照常运行；配置后 LLM 只提交意图，引擎判定结果。
- 事件日志为权威，决策可重放；可从种子 + 决策日志重建世界。
- 观看者状态里同时有 `facts`、每个居民的 `beliefs`、`chronicle`、`remains`。
- 页面上的时间轴与编年史走本地 API（`/api/timeline`、`/api/chronicle`）；不配置模型时用本地叙事器。
- 事件日志可导出成带哈希的信封（`/api/journal`）；`SYNC_MODE=peer` 下每个节点双向拉取缺失日志，按事件数轮换写入权，权威失联后由下一个节点按租约到期接任；`/api/identity` 可看角色、任期、继任者、接管倒计时、`syncFault` 与节点公钥。单主/镜像模式仍可用于演示。
- 每个节点首次启动生成 Ed25519 身份；日志信封、身份声明和写入请求都签名，对端按 TOFU 固定公钥，写入请求带时间戳与 nonce 防重放。可选用 `TLS_KEY_FILE` / `TLS_CERT_FILE` 开 HTTPS。

**B 阶段全节点轮值同步已完成（主路径）**：`SYNC_MODE=peer` 下每个节点双向拉取缺失日志，`term` 由事件数决定，同一时刻只有当前权威推进模拟；交接时先拉完日志再写。两个真实服务进程的集成测试验证了双方轮流担任权威、每个任期后状态哈希收敛；单主/镜像保留为演示/回归模式。

**B 阶段故障交接已完成**：权威失联超过 `TAKEOVER_MS` 后，轮值里的下一个节点把 `{term, authorityId, reason}` 作为 `term` 事件追加进日志并接任。排序仍然只看日志字段（term / seq / prevHash / 节点 id），墙钟只用于判断“失联多久”。旧权威带着旧存档回来时会读到更高任期，先追平、再作为跟随者参与；如果它的存档比幸存者更新（失联前最后几条事件没人拉到），以更高任期为准重建并丢弃那段旧尾巴。同一任期内真正分叉仍然记录 `syncFault` 并停写，可用 `/api/sync/adopt` 人工指定基准。集成测试覆盖：杀掉当前权威→幸存者接任并继续推进→旧权威重启后只读；以及旧权威存档领先时的重建路径。

**B 阶段节点身份签名已完成**：每个节点首次启动生成 Ed25519 密钥对，私钥只在本机文件里（`NODE_KEY_FILE`），不进存档和日志。`/api/journal` 的每个信封、`/api/identity` 的每次身份声明都由本节点签名；对端第一次接触时把公钥固定进本机信任表（`TRUST_FILE`），之后换钥匙、或同一地址换节点名都会被拒绝。`/api/journal/apply` 与 `/api/sync/adopt` 接受 token 或带 `timestamp` + `nonce` 的节点签名；服务端先验签再记录 nonce，时钟窗口默认 60 秒、nonce 保留 5 分钟，原样重放会被拒绝。日志签名者和请求签名者必须是同一节点，否则返回 403。可选 TLS 已接入（`TLS_KEY_FILE` / `TLS_CERT_FILE`）。首次信任仍是 TOFU，首次 MITM 要靠 TLS + 带外核对公钥指纹解决。

## 5. 模拟里已经能看到什么

近几次 `test-sim.js`（2.5 个世界日、5 个种子）的观察：

- 居民会因为饥饿、仇恨或野兽死亡；会出现人与人之间的冲突与凶杀。
- 收养与继承会发生；无人继承时留下遗产与空宅，后来者会搬进去。
- 脱变每局出现 3–6 次，包括“仇人死亡”“杀人后活下来”“被别人当成主心骨”。
- 制度会自己长出来：每局出现律法、教义，部分局还会出现结社。
- 语言墙生效：约一半交谈互相听不懂；2.5 天后有 3–5 人学会第二语言，另有 3–6 次明确的语言教学。
- 谣言会沿信念链漂移，但事实层逐字节不变。
- 较长的局里，长期无人提起的人“被记住”程度会降到个位数，逼近淡出；社交活跃的人保持在 40–100。

## 6. 已知缺口（明确推迟，不是遗忘）

1. **规则大脑仍是全知的**：除了知识门槛、身份倾向、语言判定，它读的是世界状态，不是自己的信念。规格第 30 条“按信念行动”只完成一半；LLM 提示词里已经带信念。
2. **脱变下限 2 次没有强制**：只保证不超过 2–5 的上限；有人没活到 2 次就死了。
3. **LLM 脱变标签现在会随日志重放**：标签写在 `turning` 事件里，重放时优先读它，不再退回确定性标签；但它不是带序号的决策记录，两台机器同时触发同一场脱变时谁先仍未定义。
4. **语言是模拟的**：三种语言用 ID + 中文文本表示，没有真正的陌生语言生成与客户端翻译层；观看者“看得懂”是设定层实现。
5. **知识教学不要求共享语言**：当作手势与示范处理，是为可玩性做的简化。
6. **祖先的声音只按“是否在关系链里”设限**，不是严格血统；玩家属于哪条血脉的身份模型还没有。
7. **离线推进有上限**：最多补 7 个世界日；超出部分只报告 `skippedTicks`，不模拟也不保留关键事件。
8. **轮值同步还不是生产级协议**：双向拉取、按事件数轮值、交接先拉后写、租约到期接管、旧权威隔离与节点身份签名已完成；但网络分区（旧权威没死、只是失联）仍会在同一任期产生分叉，需要人工 `/api/sync/adopt`；日志全量重新引导、自动冲突仲裁、拜占庭容错都还没实现。TLS 只是可选项，没有自动化测试；首次接触仍靠 TOFU，公网部署必须配 TLS 并带外核对公钥指纹。
9. **睡眠/淡出只完成“被惦记”轴**：真实在线/离线同步与浅睡未实现，留给 B 阶段。制度已经可用，但条目仍有限：律法只针对攻击，教义仪式只实现两种，争抢解释权用声望与结社权重近似，没有直接冲突。
10. **时间轴只回放关键事件与叙事**，不能把地图和每个人的状态倒回那一天重跑；真正的历史态回放留给 B 阶段的事件重放。
11. **叙事缓存只在进程内**：重启后重新生成；不同观看者的版本靠观看者 id 隔离，不能跨机器同步，也不能导出。
12. **真人上传、隐私红线、PoW、P2P** 都未开始。

## 7. 建议的下一步

架构约束已锁定在 [06-架构-B阶段.md](06-架构-B阶段.md)，peer 轮值、故障交接与节点身份签名已落地。接下来：

1. **两台真实机器手验**：照 `prototype/README.md` 的“全节点轮值”配置启动两个节点，先核对两边 `/api/identity` 的 `keyId` 与 `TRUST_FILE` 是否互相固定；再看 `role`/`term` 交替；再直接杀掉当前权威，确认 `successorId` 在一到两个 `TAKEOVER_MS` 内接任、世界继续推进；最后把旧节点拉起来，确认它变成跟随者、密钥没变且 `stateHash` 收敛。
2. **演练网络分区**：不要杀进程，改用防火墙/断网让一端失联，制造“两边都以为自己是权威”的局面，确认 `syncFault` 会停写、`/api/sync/adopt` 能人工指定基准恢复。分区合并仍然明确留白。同时确认签名请求在断开/恢复后不会被误判重放（时钟窗口默认 60 秒）。
3. **部署传输安全**：为节点生成证书并配置 `TLS_KEY_FILE` / `TLS_CERT_FILE`，把 `PEERS` 改成 `https://`；跨机器核对公钥指纹，把信任表从 TOFU 变成“带外固定”。这一步做完，才能离开可信 LAN/VPN。
4. **接真实在线/离线（睡眠轴）**，最后才是公开、存续订阅与代写一生。
