# 规格 · C 阶段：让世界自己长出社会

> 状态：ready-for-agent
> 依据：2026-11-02 的评审共识。范围 = 七个系统 + 存档/离线推进 + 事件日志 + 观看界面 v1。
> 本文件在 issue tracker 配置完成前是唯一权威版本。

---

## Problem Statement

从观看者的角度看：这个世界的雏形已经能让人连续看 30 分钟，并且出现了没预设过的事。但它仍然是一次性的——刷新就重开，离开就没有“回来”这回事。

世界里的人也还太薄：十二个人只有禀赋不同，没有语言、没有谣言、没有继承、没有制度、没有转折、没有遗忘。它现在只能演示“活着”，还不能演示“一个人的一生如何被记住”。

更具体地说：不接模型时，5 个种子、2.5 个世界日的模拟里，死亡全部来自野兽，人与人的冲突为 0。世界还不会自己长出社会。C 阶段要解决的，就是这个。

## Solution

一个单人、可以离开再回来的世界：

- 从第一天起，**事件日志是权威**；每 N 个 tick 存一次快照。重开时从最近的快照之后重放；离线期间按真实经过的时间快进，并给出一段“你不在时发生了什么”。
- 十二个人分说 2–4 种语言；出身映射成初始技能与生活知识；生存常识天生，岛上的事实从零开始，生活知识靠出身或教学。
- **事实与信念分离**：引擎记录事实，每个人有自己的信念；转述只在信念层漂移，永远不污染事实层。
- 继承只来自收养与收徒；没有生育。无人继承的人留下无主遗产，新来的人可以搬进去。
- 引擎判定转折，模型在受控词表内提议标签，每一次脱变写进编年史——而编年史由每个观看者自己的模型生成，没有官方历史。
- 制度只允许在三张固定表（律法、教义、结社）里填槽，引擎校验后对所有人生效。
- “被惦记才清醒”拆成两个轴：在线（清醒、会说话）与被惦记（不淡出）。C 阶段只验证后者。
- 观看界面三层：登录摘要 → 跟随一个人/一条血脉 → 全岛总览，加一条时间轴。观看者唯一的输入仍然是写信。

世界仍然不依赖任何官方服务器；B 阶段可以直接接在这份事件日志上做重放与排序。

## User Stories

### 观看与时间

1. 作为观看者，我想在重新打开时先看到“你不在的这段时间发生了什么”，这样我离开再回来时仍能接上这个世界。
2. 作为观看者，我想看到一段按时间排列的摘要，只包含关键事件（死亡、脱变、立法、结社、冲突、迁移），这样我不会被日常琐事淹没。
3. 作为观看者，我想在时间轴上回到任意一个世界日，这样我能补看我错过的那一天。
4. 作为观看者，我想跟随一个具体的人，这样我会牵挂他今晚有没有地方睡。
5. 作为观看者，我想在跟随和全岛总览之间切换，这样我既能看到一个人，也能看到整座岛。
6. 作为观看者，我想看一条血脉的延续，这样我能知道谁继承了谁。
7. 作为观看者，我想给任意一个居民写一句话，这样我能以祖先的声音介入而不直接控制他。
8. 作为观看者，我想知道那封信被听见、被无视，还是被误解了，这样写信才像一次真正的托付。
9. 作为观看者，我想在写信后看到冷却，这样我不会把世界变成指令台。
10. 作为观看者，我想看懂所有语言，这样我能看到当事人听不懂的对话。
11. 作为观看者，我想区分“事实”和“某个人以为的事实”，这样我能看到误会在哪里发生。
12. 作为观看者，我想选中一段事件，用我自己的模型生成一段叙事，这样同一场战争在我的版本里可以是悲剧。
13. 作为观看者，我想让我的叙事只缓存在我自己这里，这样别人的版本不会被我覆盖，也不会变成官方历史。
14. 作为观看者，我想看到一个人长期无人提起后淡出，这样“被记住”才有重量。
15. 作为观看者，我想看到一个人因为被转述、被祭拜、被写进编年史而不淡出，这样我能理解这个世界的存在规则。

### 知识与语言

16. 作为居民，我想一醒来就会走、会吃、会躲，这样我不会因为不懂生存常识立刻死掉。
17. 作为居民，我想因为出身不同而带着不同的初始技能（教师识字、猎人追踪、农夫耕种），这样我醒来的第一件事就能成为我在岛上的身份。
18. 作为居民，我想在岛上学习我不会的东西，这样“教”和“学”才有意义。
19. 作为居民，我想让技能成长速度由我的禀赋决定，这样人和人的成长曲线不同。
20. 作为居民，我想说 2–4 种语言中的一种，这样我属于某个语言群体。
21. 作为居民，我想和说同一种语言的人直接交谈，这样我们能结盟、交易、争吵。
22. 作为居民，我想在听不懂对方语言时只能靠手势、表情和声音判断，这样语言墙是真实的。
23. 作为居民，我想通过长期共处或明确教导学会另一门语言，这样跨语言的人会成为世界里的权力节点。
24. 作为居民，我想在交谈中传递技能、事实和信念，这样知识能沿着关系流动。

### 事实与信念

25. 作为世界，我想把每一件被引擎判定的事实写进事实层，这样任何叙事都不能改变发生过什么。
26. 作为居民，我想拥有自己的信念集合，每条信念带来源与确信程度，这样我可能相信一件假的事。
27. 作为居民，我想在转述时按概率删改细节，这样谣言会自己长出来。
28. 作为居民，我想让谓词沿受控词表演化（偷 → 抢 → 杀），这样一句话传三个人会变成另一件事。
29. 作为世界，我想让所有漂移只写进听众的信念，不写进事实层，这样重放永远一致。
30. 作为居民，我想按我的信念行动——指控、结盟、立法、复仇，这样误会能产生真实后果。
31. 作为居民，我想在发现事实与信念不符时修正信念，这样世界不是所有人都永远被骗。
32. 作为观看者，我想同时看到事实和某个人的信念，这样我能体会“观众比当事人懂得更多”。

### 继承

33. 作为居民，我想收养一个没有血缘的人，这样我死后有人接住我留下的一切。
34. 作为居民，我想收一个徒弟，把技能和信念传给他，这样手艺和执念都能延续。
35. 作为继承人，我想继承财产、部分技能、信念与未完成的执念，这样我不是从零开始。
36. 作为世界，我想让没有继承人的死者留下无主遗产和空宅，这样新来的人可以直接搬进去。
37. 作为世界，我想禁止生育，这样人类停止繁衍的前提不被破坏。
38. 作为居民，我想只对有真实关系的人产生“祖先的声音”的效果，这样写信不是全图广播。

### 脱变

39. 作为世界，我想在仇人死亡、埋葬亲人、被背叛、被奉为首领、杀人后活下来这些转折发生时判定脱变，这样人的一生有几个真正的节点。
40. 作为模型，我想在受控词表内提议一个脱变标签，这样我不会发明无法校验的身份。
41. 作为世界，我想校验并写入脱变标签，同时留下记录，这样每一次脱变都能被看见。
42. 作为居民，我想在一生中经历 2–5 次脱变，这样身份不是一成不变的。
43. 作为观看者，我想在编年史里看到每一次脱变及其原因，这样我能理解一个人为什么变成了另一个人。

### 制度

44. 作为居民，我想提出一条律法，只能填“条件 → 权限 / 禁令 / 刑罚”的槽位，这样规则能被引擎执行。
45. 作为居民，我想提出一条教义，只能填“条件 → 禁忌 / 仪式 / 信念传播”的槽位，这样信仰能影响行为。
46. 作为居民，我想建立一个结社，只能填“条件 → 成员 / 共同财产 / 领袖”的槽位，这样集体能拥有东西。
47. 作为世界，我想在校验失败时拒绝提案并记录原因，这样坏规则进不了世界。
48. 作为世界，我想让通过校验的制度对所有人生效，这样规则不是建议。
49. 作为居民，我想在违反制度时承受声望变化或刑罚，这样制度有代价。
50. 作为居民，我想争夺对同一条制度的解释权，这样政治从规则内部长出来。

### 存续与数据

51. 作为操作者，我想让世界每隔 N 个 tick 自动写一份快照，这样崩溃或关机不会丢掉整个世界。
52. 作为操作者，我想让事件日志只追加、不修改，这样它是可审计、可重放的权威。
53. 作为操作者，我想在重新启动时从最近快照之后重放事件，这样世界停在离开的那一刻。
54. 作为操作者，我想在离线期间按真实经过的时间快进，并把离线产生的关键事件汇总给观看者。
55. 作为操作者，我想让存档里永远不包含 API Key，这样把世界发给别人不会泄露密钥。
56. 作为操作者，我想让同一份种子、同一份事件日志重放出完全一致的世界，这样 B 阶段的同步才有地基。
57. 作为操作者，我想在没有配置任何模型时也能跑完整的世界，这样任何人都能打开、观看、演示。

### 交付节奏

58. 作为开发者，我想每两周交付一个能跑的完整世界，这样进度是可验证的，而不是靠文档。
59. 作为开发者，我想为每个系统维护一张“设定集条款 → 代码判定 → 可复现测试”的对照表，这样“完整实现”有明确的终点。
60. 作为开发者，我想让每条规则都能用一句话讲清，这样模型和人都不会理解错。

## Implementation Decisions

### 核心：事件日志成为权威

- 引入只追加的事件日志。每条事件至少有：单调递增序号、世界 tick、日/时、类型、发起者、意图、判定结果。
- 引擎是唯一的事件写入者。模型只提交“意图”，引擎校验后产生“结果”；意图与结果都入日志。
- 世界状态是事件的结果，也可以是快照。重放 = 从快照加载 → 按序号应用后续事件。
- 所有随机性来自世界种子驱动的单一随机源。现有规则大脑里那处 `Math.random()` 必须清除。
- 模型输出在重放中不允许再次调用：重放读取已记录的意图与结果。
- 系统的模块边界按职责划分：仿真核心、信念/事实、语言、继承、脱变、制度、编年史、持久化。每个模块只通过世界状态与事件交互。

### 事实层与信念层

- 事实层保存引擎判定过的事件与状态（谁在何时做了什么、谁死了、谁被选为继承人）。
- 每个居民持有信念集合。一条信念至少有：命题、来源、确信度、获得时间。信念可以是假的。
- 转述算子只作用于信念：删细节、改数量、改时间、改地点、谓词沿受控词表演化。
- 居民的所有决策输入是“他自己的信念 + 感知”，不是事实层。
- 观看者的客户端同时拿到事实与信念，并显式区分。

### 知识分层

- 三层：生存常识（天生）、技能（可成长）、事实与信念（后天获得）。
- 出身映射成初始技能表与对应的生活知识（农妇会种、渔夫会捕、匠人会建）；禀赋决定成长速度。与这座岛有关的**事实**（水源、资源、危险）一律从零开始；其余人的生活知识靠出身带来，或者通过教学获得。
- 教学是双向事件：教的人付出时间与体力，学的人按禀赋获得进度。

### 语言

- 世界生成 2–4 种语言，按“同乡”分组，每种语言有 3–6 个母语者。
- 理解判定只看“是否掌握该语言”。掌握来源：母语、学习、长期共处。
- 居民之间的交谈内容对听不懂的人是噪声；引擎仍然生成声音事件（方向、模糊距离，不给名字）。
- 观看者客户端永远翻译全部语言；这是观看者比当事人多知道的东西之一。

### 继承

- 关系类型只新增“收养”和“收徒”，没有生育。
- 继承内容：物品、据点/墙/火堆的使用权、部分技能、信念、未完成的执念。
- 无继承人时，财产与建筑变为无主；新来者可以搬入。
- “祖先的声音”只对存在真实关系链的人产生效果；其余情况按无视或误解处理。

### 脱变

- 引擎维护转折触发条件清单（仇人死亡、埋葬亲人、被背叛、被奉为首领、杀人后活下来等）。
- 触发后，模型只能在受控身份词表内提议标签；引擎校验后写入，并生成一条不可修改的编年史记录。
- 每个居民一生 2–5 次；达到上限后不再触发。
- 脱变改变行为倾向与声望，不直接改数值上限。

### 制度

三张固定表，模型只能填槽，不能发明效果：

- **律法**：条件（身份 / 关系 / 声望 / 地点 / 持有物）→ 效果（权限 / 禁令 / 刑罚）。
- **教义**：条件 → 效果（禁忌 / 仪式 / 信念传播）。
- **结社**：条件 → 效果（成员 / 共同财产 / 领袖）。

- 提案 → 语法校验 → 若通过则写入，对所有人生效；失败则记录拒绝原因。
- 违反判定由引擎执行，结果写事实层；目击者的信念另行生成。
- 同一制度允许存在多个解释，解释权通过声望、结社或冲突争夺。

### 睡眠与淡出

- 两个独立轴：**在线**（清醒、会说话 / 离线、规则驾驶的哑者）与**被惦记**（不被淡出）。
- C 阶段只实现并验证“被惦记”：转述、祭拜、编年史提及都会增加被惦记程度；长期无人提起则逐步淡出，最终被世界抹去。
- 在线轴在 C 阶段默认全部为离线（虚构居民由规则驾驶），B 阶段再接真实在线状态。

### 编年史

- 事实层由引擎记录，任何观看者的叙事都不能改动它。
- 叙事按“观看者 + 事件段”生成并缓存；叙事生成器是注入的接口，生产环境用观看者自己的模型，测试环境用假实现。
- 没有全局共享的官方历史；两个观看者对同一段事实可以拿到不同的文本。
- 编年史条目至少包含：事件范围、涉及的人、地点、结果、以及该观看者版本的叙事。

### 持久化与离线推进

- 每 N 个 tick 写一次世界快照；事件日志持续追加。
- 存档格式不包含 API Key、模型配置，只包含世界与事件。
- 加载 = 最近快照 + 之后的事件重放。
- 离线推进 = 按真实经过的时间换算成 tick 数，在加载时补跑；补跑有上限，超出部分只保留关键事件。
- 离线摘要只列关键事件，并附上“谁还在、谁不在了、谁的位置变了”。

### 观看界面 v1

- 三层：登录摘要 → 跟随（一个人或一条血脉）→ 全岛总览；加一条可回到任意世界日的时间轴。
- 观看者唯一输入是写信；没有投票、投喂、托梦等干预。
- 状态推送的契约需要扩展：离线摘要、时间轴、跟随目标、事实/信念标记、翻译后的对话、被惦记程度。
- 界面继续由本地零依赖进程提供；不引入构建工具。

### 兼容与迁移

- 现有原型没有跨天存档，因此不需要迁移旧存档；新格式从 C 第一天生效。
- 现有规则大脑保留为“没有配置模型时的兜底”，但必须清除其中的 `Math.random()`。

## Testing Decisions

### 什么是好测试

- 只测外部行为：给定种子、动作序列和 tick 数，断言世界状态、事实层、信念层、事件日志与摘要。
- 不测内部函数调用顺序、不测私有字段、不 mock 引擎内部。
- 所有测试必须离线、确定、无需 API Key；真实模型只用于手工验收。
- 系统测试的断言对象应是“观看者能看到的东西”加上“事实层可重放的东西”。

### 三条测试缝

**缝 1：种子世界 + tick（现有，最高）**

从 `createWorld(seed)` 起，直接注入 agent 动作、跑 N 个 tick、断言。现有测试已经证明这条缝够用：一个测试按分布跑多个种子，一个测试隔离单个 agent 后直接设置动作。

- 七个系统的行为测试全部走这条缝。
- 每个系统一张对照表：设定集条款 → 代码判定点 → 测试名。
- 断言：事件类型与数量、事实层变化、信念漂移方向、继承链、制度生效范围、淡出进度。

**缝 2：序列化与重放（新增）**

`serializeWorld` / `loadWorld`，以及从快照继续重放。

- 往返测试：存档 → 加载 → 状态哈希一致。
- 继续测试：存档 → 加载 → 再跑 N tick == 不中断跑 N tick。
- 重放测试：同一事件日志重放两次 → 哈希一致；换机器/进程顺序不影响结果。
- 离线测试：模拟经过的真实时间 → 补跑 tick 数正确；摘要只含关键事件。
- 密钥测试：存档中不存在 API Key 的任何形式。

**缝 3：叙事生成（新增）**

`chronicle(world, viewerId, range, narrator)`，narrator 注入。

- 假 narrator：同一事实换两个假 narrator → 文本不同；事实层哈希不变。
- 缓存：同一观看者 + 同一事件段第二次生成不调用 narrator。
- 隔离：观看者 A 的叙事不写进观看者 B 的缓存。
- 事实不变：生成叙事前后，事实层与事件日志逐字节一致。

### 先例

- 分布测试：多个种子跑 2.5 个世界日，检查死亡、建造、冲突的分布。
- 隔离测试：把除一个 agent 外的所有人置为死亡，直接设置动作，跑固定 tick 后断言。
- 新增测试沿用这两种写法，不引入测试框架之外的东西。

### 手工验收

- 30 分钟连续观看，中途不切走。
- 至少出现一个未预设的事件，且涉及谣言、继承、制度或脱变中的一种。
- 截一段发给人，对方问“这是什么”。
- 真实模型的接入、翻译、叙事各手验一次。

## Out of Scope

- B 阶段：两台机器、P2P 传输、轮值排序、断线重连。
- 真人上传、隐私同意流程、不可删除数据的处置。
- 公网发布、账户、支付、存续订阅的计费实现。
- PoW 防刷、身份系统。
- 异步看台、名人录、事件讨论等多人功能。
- 生育（已从设定中删除）。
- 视觉与动效的进一步打磨；只做观看界面 v1 必需的交互。
- 移动端、国际化、部署流水线。

## Further Notes

### 需要同步修改的设定文档

- 删除“生育作为可选变体”，明确继承只来自收养与收徒。
- 增加事实层 / 信念层的区分，并声明“漂移只写信念”。
- 把“睡眠/淡出”拆成在线与被惦记两个轴。
- 把制度具体化为三张固定表的槽位。
- 写明语言为 2–4 种、按同乡分组。
- 写明事件日志为权威、快照只用于加速。
- 把变现主线收敛为存续订阅；代写一生列为 runway 用完时的服务线。

### 硬标准

- 每条规则一句话。需要两句话的规则，砍掉或重写。
- 任何新系统都不得让模型决定胜负、生死或事实；模型只能提案和说话。
- 每两周必须有一个能跑的完整世界；对照表可以滞后，能跑的世界不能。

### 失败信号

- 制度变成一个通用规则引擎。
- 事实层被叙事或模型污染，重放对不上。
- 为了七条规则全上，把世界调成什么都发生一点、什么都不深。
- 离线补跑把真实时间换算错，世界“跳过”了几天。

### 开放问题（不阻塞实现）

- “被惦记”的具体计分与衰减曲线。
- 离线推进的上限与关键事件筛选标准。
- 受控身份词表的初始规模。
- 12 个虚构居民的语言分组与初始技能映射表。
